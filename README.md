# ema_strategy

黄金眼三金叉选股策略,数据源 [xtdata](http://dict.thinktrader.net/nativeApi/start_now.html)(迅投 QMT / miniQMT)。

## 选股规则

三个金叉必须**依次出现**:

| | 金叉 | 角色 | K线要求 |
|---|---|---|---|
| 1号 | MA5 上穿 MA10 | **启动点** | 贯穿 |
| 2号 | MA5 上穿 MA30 | 中间确认 | — |
| 3号 | MA10 上穿 MA30 | **确认点** | 跳空 |

三者按 `1 → 2 → 3` 顺序完成,且启动点为贯穿、确认点为跳空 → **确认点当日触发**,次日开盘买入(A股 T+1)。

K线与均线的位置关系(比较一律取等号,相等归入 `>=` 一侧):

- **跳空** `low >= max(MA5, MA10, MA30)`
- **贯穿** 任一均线落在 `[low, high]` 内
- **均线下方** `high < min(MA5, MA10, MA30)`
- **其他** 整根K线夹在两条均线之间,不触碰任何一条

`low == max(MA)` 时跳空与贯穿同时成立,按取等号规则判为**跳空**。

## 用法

```bash
# 全市场选股
python -m ema_strategy --date 20260904 --out picks.csv

# 单票诊断:逐条打印每个条件的实际取值
python -m ema_strategy --date 20260904 --explain 000001.SZ

# 放宽「启动点须贯穿」
python -m ema_strategy --date 20260904 --no-start-bar

# 样本统计(--csv-dir 可用本地CSV,不依赖 QMT)
python scripts/backtest.py --start 20220101 --end 20260904
python scripts/backtest.py --csv-dir tests
```

## xtdata 的两个危险默认值

`get_market_data_ex` 的默认参数会**静默污染信号**,本包已强制改掉:

1. **`dividend_type` 默认 `'none'`(不复权)** —— 除权日会凭空出现假金叉/假死叉。
   本包用 `'back'`(后复权):历史不 repaint。
   **不要用 `'front'`(前复权)**:每遇新的除权就把全部历史重算一遍,过去的均线值会变,
   用于信号生成等于引入未来信息,只适合看图。
2. **`fill_data` 默认 `True`** —— 停牌日被前值填充成成交量为 0 的假K线。
   这种K线 `low == high == close`,必然被判成「贯穿」,直接污染启动点判定。
   本包固定 `False`,并按 `volume <= 0` 二次过滤。

## A股落地细节

- **涨跌停**按板块区分:主板 10%、创业板/科创板 20%、北交所 30%、ST主板 5%
  (ST 创业板/科创板仍是 20%,不是 5%)。
- **涨停价用 `Decimal` 四舍五入到分**。Python 内建 `round(3.465, 2)` 得 3.46,
  交易所是 3.47 —— 差一分会导致一字板漏判。
- **一字涨停过滤**放在 `attach_tradability()`,因为次日开盘价要到次日才有,
  这是下单前的最后一道闸,不在 `evaluate()` 内。
- **长期停牌**:跨越停牌的均线没有意义,`gap_flags()` 标记超过 30 自然日的缺口并剔除。
- 股票池默认剔除 ST、上市不足 120 天的次新、已退市。

## 规则未定义、本实现补充的约定

都在 `sequence.Params` 里,可调:

| 参数 | 默认 | 说明 |
|---|---|---|
| `abort_on_dead_cross` | `True` | 等待 2/3 号期间 MA5 下穿 MA10 则序列作废。不加这条,一个很久以前的1号金叉能和数月后的3号金叉凑成一对 |
| `max_span` | `60` | 1号到3号的最大间隔交易日。实测真实间隔中位数 5–6 日、最大 13 日,60 很宽松 |
| `require_distinct_days` | `False` | 是否要求三个金叉分属不同交易日(跳空高开可能一次上穿两条均线) |
| `ma_kind` | `"sma"` | 均线口径。原始规则未指明加权方式 |

期间再次出现1号金叉时,以**最新**的为准并重置2号。

## 样本统计

> **以下数字来自美股样本(INTC/GOOG/AAPL,9091 根真实日线),不是 A 股。**
> 开发环境无法访问任何 A 股数据源,这些数字仅用于验证实现、观察规则方向性,
> **不代表策略在 A 股的有效性**。请用 `scripts/backtest.py` 在你的 xtdata 上复跑。

140 条完整三金叉序列,其中 32 条触发。确认点次日开盘买入:

| 持有 | 触发(32) | 未触发(108) |
|---|---|---|
| 5日 | +0.68% / 59.4% | +0.39% / 50.0% |
| 10日 | **+3.08% / 71.9%** | +0.74% / 59.3% |
| 20日 | +3.45% / 59.4% | +1.83% / 61.1% |
| 30日 | +4.35% / 65.6% | +2.91% / 62.0% |

两个形态条件的交叉(持有20日):

| 启动贯穿 | 确认跳空 | 次数 | 平均 | 胜率 |
|---|---|---|---|---|
| 是 | 是 | 32 | **+3.45%** | 59.4% |
| 否 | 是 | 33 | +2.22% | 66.7% |
| 是 | 否 | 41 | +1.87% | 58.5% |
| 否 | 否 | 34 | +1.38% | 58.8% |

完整规则(两个条件都满足)平均收益最高。样本量偏小(32 笔),仅供参考。

## 测试

```bash
python -m pytest
```

80 项测试,不需要 QMT 环境。测试数据取自 matplotlib/mplfinance 仓库的公开示例
(BSD 许可),选它们是为了让全部测试在任何平台都能跑通。

覆盖:K线分类的四种情形与取等号边界、金叉/死叉、三金叉序列的顺序不变量、
`max_span`/`abort_on_dead_cross`/`require_distinct_days` 的效果、
涨跌停价的 Decimal 舍入、停牌假K线清洗、`evaluate` 与 `explain` 的逐日结论一致性。

其中一项是回归测试:`cross_up` 曾在均线预热期结束的第一根K线上误报金叉
(`a >= b` 在 NaN 期为 False、转正后跳到 True),导致每只股票在 MA30 预热结束当天
凭空多出 1/2/3 号金叉,足以凑出一条完整的假序列。现已要求前一根K线两条均线都有值。

## 局限

- **取数层未在真实环境验证过**。`xtquant` 是 Windows-only 且需要 QMT 客户端,
  开发环境只核对了 API 签名(xtquant 250807.1.2),纯计算层则全部测试通过。
- **所有统计数字都不是 A 股**,见上。
- 策略只实现三金叉触发规则,**不含**卖出/止损逻辑与仓位管理。
